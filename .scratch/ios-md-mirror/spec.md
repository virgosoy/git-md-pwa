# SPEC — iOS 私有 Markdown 离线镜像 PWA

目标：零成本、个人自用，在 iPhone 上把用户自己的 GitHub **私有** Markdown 笔记库「镜像」下来离线阅读。Windows 开发（无 Mac）、无自建服务器、不花钱。笔记库信息属隐私，只存用户设备本地，绝不进入本公开仓库。

## 已确认设计

| 域 | 决定 |
|---|---|
| 交付 | 纯 PWA（Vite + TS + Preact），GitHub Pages 托管，Safari「加到主屏幕」 |
| 授权 | 细粒度**只读** PAT（Contents + Metadata read），设置页粘贴，只存 App 自己的 IndexedDB |
| 仓库 | 单仓库；owner/repo 由用户在设置里填写，运行时常量；不硬编码、不提交 |
| 镜像 | 只镜像 `.md`（约 8M）；单文件 >10MB 跳过并标注「未镜像」 |
| 资源 | 图片/PDF 懒加载：联网打开笔记时静默拉取引用资源并缓存；离线显示已缓存 + 占位符；「本篇资源全下」按钮 |
| 浏览 | 目录树 + 正文阅读器 + 最近打开 + 阅读位置记忆 + 全局标题/文件名搜索 + 单篇笔记内查找（应用内；PWA 独立模式无 Safari 原生 find） |
| 互链 | `[]()` 内链 → App 内跳转；`http(s)` 外链 → 系统浏览器；`![]()` 图 → 懒加载 |
| 同步 | 设置开关（**默认开**）；打开时以默认分支最新 commit 为版本号增量同步；手动「刷新」；失败沿用旧镜像 + 顶部「离线 · 上次同步 x 分钟前」 |
| 渲染 | CommonMark（含表格）+ 代码高亮 + 原始 HTML 透传（ADR-0002）；公式（KaTeX 0.19）与 Mermaid（`~10.9.8` backport，兼容 iOS16）为**按需渲染**：设置页两个开关控制，**默认关**（关/错=静默当源码，ADR-0003） |
| 开发 | 敏捷、功能队列驱动（见 ticket 序号），无版本切分 |

## 功能队列（票即队列）

`01 骨架 → 02 镜像核心 → 03 阅读器 → 04 同步 → 05 资源懒加载 → 06 全局标题搜索`；`07a 公式渲染 ✓（已交付，ADR-0003）`；`07b Mermaid 渲染 ✓（代码已交付，待 iPhone14/iOS16.1.1 真机 flowchart 出图后记 resolved）`；`08 单篇 TOC ✓（已交付）`；`09 单篇正文查找 ✓（已交付，2026-11-11，待 iPhone 手验）`；`12 全文搜索 ✓（已交付，2026-11-13）`；未排期：回写 push、收藏、深色主题、检索结果排序优化、单篇 TOC 内搜索、检索展示优化、mermaid 升 v12（待 iOS 升级）。

## 验收基线

- 设置（PAT + owner/repo）后能拉取文件树并离线打开一篇 md 渲染阅读。
- 断网打开仍可用旧镜像；联网打开自动增量，手动刷新可用。
- 同步开关默认为开，关闭后不再自动同步。
- 仓库内任何提交的文件/git 历史不含笔记库痕迹（隐私红线）。
