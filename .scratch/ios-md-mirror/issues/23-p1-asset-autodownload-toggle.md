# 23 · P1 资源自动下载开关（默认开；关闭后只显示已缓存）

单篇阅读时，资源（图片 / PDF 等附件链接）现在会在打开笔记时自动联网拉取并缓存。新增设置「打开笔记时自动下载图片与附件资源」（**默认勾选**）；关闭后打开笔记不发起任何资源网络请求，只显示本机已缓存资源，未缓存的显示「未下载」并可点单个下载；「本篇资源全下」永远可用（显式动作无视开关）。

**完成定义**：

- 默认开 = 现有行为零变化。
- 关闭后打开含未缓存资源的笔记：零资源网络请求；已缓存照常显示；未缓存图片显示「未下载」占位、附件链接追加「（未下载）」。
- 点单张「未下载」只请求该路径并就地回填；「全下」请求本篇全部并回填，均不受开关影响。
- 「未镜像」仅保留给尝试后失败 / 超 10MB。
- 测试：settings 默认值 + SettingsView 渲染 + wireAssets 三态 + App 集成（关开关后打开笔记零资源请求，全下后出现请求）；`npm test` / `typecheck` / `verify:pwa` 全绿；隐私自查（全部哑值）。

## 决策（2026-11-22 grilling）

- **一个开关覆盖图片 + 附件链接**（不拆两个）：用户诉求是「不要任何自动下载」；两个开关会分化占位/全下语义，还要处理 4 种组合。
- **关闭 = 不联网，而非不显示**：已缓存的照常显示（只读 IDB），保住离线阅读。
- **两类「没有图」分开**：「未下载」（开关关着，没试）vs「未镜像」（试过但离线失败 / 超 10MB）。
- **「全下」和单张点击都是显式动作**，永远可下载；单张下载失败降级为「未镜像」，仍可再点重试。
- 字段 `autoDownloadAssets`（默认 `true`）；设置项放在「自动同步」下方；新占位常量 `NOT_LOADED_IMG`（灰色「未下载」）。
- 不做 iPhone 专属验收（非 iOS 特有行为），下次 push 顺带覆盖。
