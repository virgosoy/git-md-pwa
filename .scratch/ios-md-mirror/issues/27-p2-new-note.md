# 27 · P2 新建笔记：在手机上创建 Markdown 文件并提交回私有仓库

目标：在主屏 PWA 里新建一个现有目录下的 `.md` 文件，提交到私有仓库默认分支，随后进入编辑器写正文。新建属于回写能力，跟随 `writeBackEnabled` 开关（默认关闭），不改变「镜像不是 Git 工作副本」的语义（ADR-0005）。

**范围**：新建单个文件；目录从既有镜像目录中选择。不做新建目录、删除/重命名/移动、模板、附件上传、离线排队、行级 diff。

## 完成定义

### 入口与门控

- 首页顶栏在「刷新」「设置」旁新增「＋」按钮；仅 `writeBackEnabled && token 非空` 时显示（与阅读器 ✏️ 共用 `writeUi` 门控）。
- 点击打开「新建笔记」弹层（与 `ConflictPanel` 相同的遮罩面板形态，含移动端安全区）。
- 回写关闭或令牌为空：首页不出现「＋」；应用内无其他深链入口。

### 弹层

- 字段：目录下拉 + 文件名输入框 +「创建」/「取消」。
- 目录下拉数据：从当前镜像 `files` 的 path 去掉文件名得到所有目录路径（含嵌套），去重排序；首项固定「/（根目录）」；默认根目录，本次会话内记住上次选择，不写入设置。
- 目录只读来自镜像：不扫描远端、不新建目录。
- 文件名规则（纯函数，见测试缝）：
  - 去除首尾空白；为空时「创建」禁用。
  - 不以 `.md` 结尾（大小写不敏感）则自动补 `.md`；已是 `.md`/`.MD` 不重复补。
  - 允许中文、空格、emoji，保持用户输入的大小写。
  - 拒绝含 `/`、`\`、控制字符（U+0000–U+001F、U+007F），以及整名等于 `.` 或 `..`；在弹层内提示，不发起请求。
- 创建中：按钮显示「创建中…」并禁用，用 ref 守卫防止重复点击（同 `savingRef`）。
- 取消、点遮罩：关闭弹层，不发请求。

### 创建

- 提交：`PUT /repos/{owner}/{repo}/contents/{path}`，body 含 `message: 手机新建：<path>`、`content`（空文件，UTF-8 → base64），**不带 `sha`**、不带 `branch`（默认分支）。
- 不发送 `X-GitHub-Api-Version`（现有客户端已保证）；超时沿用 30s（`withTimeoutReject`），按网络错误处理。
- 成功：用响应 `content.sha` 与空正文 `upsertFile({ path, sha, content: '', size: 0, status: 'ok' })`；刷新 `files`（首页列表与搜索索引自动重算）；`openNote(path)`（写入最近打开）；随即进入编辑器（`baseSha` = 新 sha，`baseContent` = `''`，`eol` = `lf`）。
- **不**修改 mirror meta 的 `commitSha`，不做整树同步；下次同步按 sha diff 自然校准。
- 本地回填失败按票 26 的容错处理：不阻断「已创建」结果，不额外报错；下次同步校准。

### 重名与错误

- 本地镜像已有同 path：弹层内提示「已存在同名笔记」，不发请求。
- 远端 PUT 返回 409/422：用 `getFileContent` 确认——
  - 远端存在：提示「已存在同名笔记」，保留输入，不覆盖、不自动改名；
  - 远端不存在或读取失败：显示 GitHub 原始 message，或「新建失败，请稍后再试」。
- 403：提示「当前令牌没有写权限，请到设置换成 Contents: Read and write 的令牌」。
- 401：显示 GitHub 原始 message（与票 26 一致）。
- 网络错误/超时：提示「新建失败，需要联网后再试」。
- 所有失败：弹层保持打开、输入保留，**不落草稿**，镜像不变。

### 创建后的导航

- 创建成功直接进编辑器；编辑器「返回」→ 阅读器显示这篇新笔记；再返回 → 首页（列表已含新条目）。
- 创建成功后清空首页搜索词，避免返回时新笔记被旧查询过滤掉看不见。
- 编辑器里丢弃草稿只删草稿；已创建的空文件保留在仓库与镜像中（文案不暗示笔记被删除）。

### 文档与版本

- `package.json` 版本按仓库惯例递增（0.0.7 → 0.0.8）。
- ADR-0005：正文补充「新建走同一端点、省略 `sha`、提交说明 `手机新建：<path>`」；Consequences 里「新建、删除、重命名、附件上传不在本版」改为「新建已纳入（仅新建文件，不含新建目录）；删除/重命名/附件上传仍不做」，并补一条「新建先提交空文件，首次保存产生第二个提交」。
- `spec.md` 功能队列：标出票 27 已排期；「未排期」保留新建目录、收藏、mermaid 升 v12。
- `draft.md`：记录「新建目录」为后续待办。

## 事实依据（2026-11-27 核对）

- Contents API：不带 `sha` 的 PUT 在文件不存在时创建文件；路径已存在时返回 422（`sha` wasn't supplied），需按疑似重复处理并 GET 确认。
- 响应里的 `content.sha` 是新文件的 blob sha；创建空文件时 `content` 为 `encodeUtf8Base64('')`。
- `src/github/client.ts` 的 `putFile` 已支持省略 `sha`；`encodePath` 已处理中文/空格/emoji 的路径编码。
- 首页列表与搜索索引都由 `files`（IDB `mirror`）派生（`buildIndex(files, …)`），`upsertFile` + `refreshFiles` 即可让新笔记出现在列表与搜索里。
- `getFileContent` 对 0 字节文件返回空正文（`size === 0` 分支），因此创建后进入编辑器/阅读器不需要额外特判。
- 草稿按 path 唯一；创建后进入编辑器即进入票 26 的既有草稿/保存/冲突链路。
- 参考：GitHub Docs — Repository contents、ADR-0005。

## 决策（2026-11-27 与用户确认）

- 先创建再编辑（A）；不做「编辑器草稿态、首次保存才创建」。
- 入口为首页顶栏「＋」，弹层内选目录。
- 目录只从既有镜像目录中选择；**新建目录记入后续**，本期不做。
- 初始正文为空文件；不提供模板，也不在弹层里填正文。
- 同名不覆盖、不自动改名；弹层内提示并保留输入。
- 创建必须在线；失败保留弹层输入，不落草稿。
- 文件名只填名字；自动补 `.md`；允许中文/空格/emoji；拒绝路径分隔符与控制字符。
- 创建成功进编辑器，返回落阅读器。
- 提交说明 `手机新建：<path>`；成功后用响应 sha 回填、不整树同步、不改 mirror meta。

## 测试缝

纯函数单测（哑值）：

- 文件名规范化：补 `.md`、`.MD` 不重复补、首尾空白、中文/空格/emoji 保留、拒绝 `/` `\` 控制字符、`.` / `..`、空名。
- 目录列表推导：从 `files` 的 path 去文件名、去重、排序、根目录固定首项。
- 新建提交说明生成：`手机新建：notes/哑值.md`。

集成（stub fetch + 预置 IndexedDB；render `<App/>` 前先 `vi.mock('virtual:pwa-register/preact')`）：

- 回写关 / 令牌空：首页无「＋」。
- 创建成功：请求体无 `sha`、message 为 `手机新建：…`、content 为空串的 base64；mirror 新增该 path；首页列表出现；编辑器打开且正文为空；最近打开含该 path。
- 创建成功后编辑器返回：阅读器显示该新笔记；再返回首页。
- 本地同名：不发请求，弹层提示。
- 远端 422 + GET 确认存在：提示同名、保留输入、无覆盖请求。
- 403：提示换读写令牌。
- 断网/超时：提示需联网，弹层保留，mirror 无新记录、无草稿。
- 目录下拉包含镜像中的全部目录且默认根目录。
- 连续点击「创建」只发一次 PUT。

真机验收（iPhone 14 / iOS 16.1.1 Safari 主屏）：

- 首页「＋」→ 选目录 + 输入中文名 → 创建 → GitHub 出现 `手机新建：<path>` 的空文件提交 → 编辑器打开。
- 写正文并保存 → 出现 `手机编辑：<path>` 提交，正文与手机一致。
- 本地已有同名 / 先在网页建同名 → 弹层提示，不覆盖。
- 离线创建 → 提示需联网，弹层输入不丢；恢复网络后重试成功。
- 键盘弹出时弹层字段可滚动、创建可达；取消与点遮罩不产生提交。
- 新建后返回阅读器与首页，列表、最近打开、文件名搜索都能找到新笔记。
