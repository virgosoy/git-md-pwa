# Markdown 渲染放行原始 HTML，不做净化

Status: accepted

仓库里的 md 内含较多的 `<style>` + class 形式的 HTML 片段，笔记排版依赖它们。因此本应用渲染 md 时**放行原始 HTML**（不做 DOMPurify 式净化，也不把 markdown-it 设成 html:false）。成立前提：内容是用户自己的私有仓库，且只在用户自己设备上查看——信任边界内没有不可信输入。

代价与边界：渲染与浏览的安全姿态被绑在「仅本人、仅私有」这个前提上。一旦未来引入他人协作内容或公开内容，必须先引入净化，再扩展渲染能力。

## Considered Options

- **默认净化 + 白名单标签**：更「安全」，但 `<style>` 与任意 class 结构要么被拆、要么列不完，必然破坏一部分现有排版；且当前威胁模型下没有收益。
- **放行原始 HTML（采用）**：零破坏、实现简单，前提（私有+单用户）现在成立。

## Consequences

- 渲染器需关闭对 HTML 的自动转义；`<style>` 注入需注意作用域，避免污染应用自身的 UI 样式。
- 将来若开放协作/公开，此决策要重新评估（届时是 ADR-0001 类的大决定，会 supersede 本 ADR）。
